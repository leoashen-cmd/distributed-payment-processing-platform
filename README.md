# Distributed Payment Processing Platform

A scalable payment processing platform designed to demonstrate secure transaction management, fraud detection, event-driven architecture, API development, and reliable financial data processing.

## Features

- Secure payment processing
- Transaction lifecycle management
- Fraud detection
- Idempotent transactions
- REST API
- Event-driven architecture
- Transaction history
- Authentication and authorization
- Automated testing
- Health monitoring

## Technologies

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Redis
- Pydantic
- Pytest
- Docker
